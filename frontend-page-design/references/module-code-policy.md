# 权限码占位规则

> 本文件被 [SKILL.md](../SKILL.md) Step 7-8 引用。规定新模块未分配权限编码时如何选占位 + 强制 TODO 注释。
>
> **本文件描述占位策略,不预设项目具体权限码常量名**。具体常量(如 `MODULE_CODE.XXX` / `PERM.YYY`)以项目现有定义为准——SKILL.md Step 1 探测参考页时一并抽取。

## 为什么需要占位

项目通常有一套权限编码体系(常见名 `MODULE_CODE` / `PERM` / `AUTH_CODE` 等),由后端分配。新模块上线前:
- 后端可能还没建权限位
- 但前端要先能跑路由 + 菜单

所以借用相近模块的权限码占位,**必须**加 TODO 注释让未来能找到所有待处理项。

## 占位选择优先级

按以下原则选最贴近的:

| 新模块类型 | 占位选择 |
|---|---|
| 跟现有模块业务高度相似 | 借用该现有模块的权限码 |
| 同业务域的另一类(如设置/列表/详情) | 借用同业务域里语义最近的权限码 |
| **找不到相近的(兜底)** | 用项目里"工作台"或"所有人可见"类的兜底常量(常见名 `WORKBENCH` / `HOME` / `COMMON` 等) |

具体常量名以**项目权限码定义文件**(常见路径 `<接口目录>/role/define.ts` 或类似)实际定义为准。

## 强制 TODO 注释格式

```ts
meta: {
  moduleCode: <项目权限码常量>.<占位项>,
  // TODO(perm): 暂用 <占位项> 占位,后端分配真实权限ID后替换为 <预期常量名>
  // 见 <项目权限码定义文件> 的 <常量枚举>
}
```

**关键**:`TODO(perm):` 前缀让以下命令能一次性找出所有待处理占位:

```bash
grep -rn "TODO(perm)" src/
```

## 菜单同步占位

项目菜单文件(常见名 `useMenu.ts` / `menu.ts` / `sidebar.ts` 等)里的菜单项也需要同样的占位 + 注释:

```ts
{
  moduleCode: <项目权限码常量>.<占位项>,   // TODO(perm): 后端分配后替换
  name: '<中文名>',
  key: '<module>',
  icon: <借用的图标>,                       // TODO(icon): 设计出图后替换为专属图标
  iconSelected: <借用的图标-选中态>,
  path: '/<module>',
}
```

项目图标资源目录以现有约定为准(常见 `src/assets/svg/menu/` / `src/assets/icons/` 等)。新模块图标未到位时**先用相近模块的图标占位**。

## 临时方案:绕过权限检查

如果占位 ID 不在用户权限范围(导致菜单不显示),看项目是否有"绕过权限检查"的开关字段。常见模式:

```ts
{
  moduleCode: <兜底常量>,
  name: '<中文名>',
  key: '<module>',
  authRequiredFalse: true,   // 临时:绕过权限检查,所有人可见(字段名以项目实际为准)
  // TODO(perm): 后端分配权限后删除此行
}
```

字段名以项目菜单/路由定义里实际支持的为准。如果项目没这种开关,改用兜底常量绕过。**上线前必须删除临时开关**。

## 后端分配后的替换流程

```bash
# 1. 找出所有占位
grep -rn "TODO(perm)" src/

# 2. 逐一替换:
#    - 把占位常量改成后端分配的真实常量
#    - 把借用的图标改成专属图标(如已设计)
#    - 删除临时绕过开关(如有)

# 3. 验证:
npx vue-tsc --noEmit
# 跑一次 playwright smoke 确认菜单正常
```
